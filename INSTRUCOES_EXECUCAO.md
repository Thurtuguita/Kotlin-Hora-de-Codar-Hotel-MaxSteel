Hotel MaxSteel — Instruções de Execução

Requisitos
Para executar o projeto, é necessário ter:
•	IntelliJ IDEA; 
•	Kotlin configurado no projeto; 
•	JDK compatível com a versão do Kotlin utilizada. 


Como executar
1.	Abrir o projeto do Hotel MaxSteel no IntelliJ IDEA. 
2.	Verificar se todos os arquivos .kt estão dentro do projeto. 
3.	Localizar o arquivo que contém a função main(). 
4.	Executar a função main() utilizando o botão Run do IntelliJ IDEA. 
5.	O sistema exibirá a mensagem inicial e solicitará o nome do usuário. 
6.	Em seguida, será solicitada a senha de acesso. 
7.	A senha definida no sistema é 2678. 
8.	Após o login, será exibido o menu principal com as opções: 
o	Reservas de Quartos; 
o	Cadastro de Hóspedes; 
o	Eventos; 
o	Ar-Condicionado; 
o	Abastecimento; 
o	Relatórios Operacionais; 
o	Sair.

O sistema funciona por meio de menus e entradas fornecidas pelo usuário durante a execução.
